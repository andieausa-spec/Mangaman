# TRENDY STUDIO (Desktop-Testversion)

DAW von Andreas Engel, Darmstadt. Die Oberfläche ist dieselbe wie in der Browser-Fassung (`app/index.html`),
hier verpackt als macOS-App (Electron, Universal: Apple Silicon + Intel).

Gebaut wird per GitHub Actions (`.github/workflows/trendy-studio.yml`) bei jedem Push auf diesen Ordner.
Ergebnis: `TrendyStudio-<Version>-macOS.dmg` als Release `trendy-studio-v<Version>`.

Lokal: `npm install && npm start`.
