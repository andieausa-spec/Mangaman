JARRE MACHINE – Installation auf dem Mac
========================================
Space-Track-Generator, Version 0.1 – Andreas Engel, Darmstadt, Deutschland

1. Doppelklick auf „JARRE MACHINE Installer.pkg“.

   Meldet macOS „kann nicht geöffnet werden, da der Entwickler nicht verifiziert ist“:
   Systemeinstellungen → Datenschutz & Sicherheit → ganz nach unten scrollen →
   bei „JARRE MACHINE Installer.pkg wurde blockiert“ auf „Trotzdem öffnen“ klicken.
   (Der Installer ist nicht mit einer Apple-Developer-ID signiert.)

2. Der Installer legt ab:
   - AU-Instrument:   /Library/Audio/Plug-Ins/Components/JARRE MACHINE.component  (Logic, GarageBand)
   - VST3-Instrument: /Library/Audio/Plug-Ins/VST3/JARRE MACHINE.vst3             (Cubase, Ableton Live, Bitwig …)
   - Standalone:      /Programme/JARRE MACHINE.app

3. DAW neu starten.
   Logic: Neue Software-Instrument-Spur → Instrument → AU-Instrumente → Andreas Engel → JARRE MACHINE.
   Cubase: Instrumentenspur hinzufügen → JARRE MACHINE (Hersteller Andreas Engel).
   Ableton Live: Einstellungen → Plug-ins → „VST3-Plug-in-Systemordner verwenden“ an → „Neu scannen“.

4. Auf START drücken. Der Track läuft mit dem Tempo der DAW, wenn sie spielt,
   sonst mit seiner eigenen Uhr. NEUER TRACK würfelt einen ganz neuen Track.

Läuft auf macOS 11 oder neuer, Apple Silicon und Intel.
